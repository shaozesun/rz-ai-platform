# 综合管理平台接口参数映射确认清单

> 用途：请贵平台按本清单核对各接口的**请求参数**（字段名、类型、必填、默认值、取值含义）。
> 我方当前按本清单传参；如与实际不符，请在最后一列「平台确认」标注正确的字段名/类型/说明，我方据此修正 `param_map`。

## 约定
- 我方内部参数用 `snake_case`，请求时按映射转为平台字段（`camelCase`）；未列映射的参数原样传递。
- `deptId`/`companyId` 若标注「服务账号兜底」，表示未显式传参时由我方按服务账号上下文自动填充。
- 分页参数：我方默认带 `page` + `pageSize`/`size`，具体见各接口。
- Base URL：`MGMT` = `http://192.168.88.18/center`；`INSPECT` = `http://192.168.88.18`（巡检服务根路径）。

## 技能说明

本技能用于快速分析数据中心运维团队的人员构成情况，帮助管理者了解团队结构。

## 触发条件

用户输入：**123**

## 执行流程

1. **获取公司列表**：调用 `mgmt__query_company_list` 获取当前账号可见的所有公司
2. **获取部门列表**：调用 `mgmt__query_dept_list` 获取各部门信息（默认使用服务账号所属公司）
3. **统计各部门人数**：对每个部门调用 `mgmt__query_user_list` 获取人员列表，统计人数
4. **分析人员专业构成**：从人员列表中提取"专业"字段（供配电/制冷/智能化等），统计各专业人员数量
5. **分析工作年限分布**：从人员列表中提取"工作年限"字段，按年限区间统计（如 0-3 年、3-5 年、5-10 年、10 年以上）
6. **生成可视化图表**：
   - 各部门人数对比柱状图（column）
   - 人员专业构成饼图（pie）
   - 工作年限分布直方图（histogram）或箱线图（boxplot）
7. **输出分析报告**：以表格 + 图表形式呈现统计结果

## 注意事项

1. 分页处理：`mgmt__query_user_list` 返回分页数据，需循环获取所有页（page=1,2,3...）直到取完全部人员
2. 数据聚合：在 Python 沙箱中使用 pandas 进行数据聚合分析
3. 图表规范：数据点少于 3 个时不强行出图
4. 时间范围：工作年限按当前年份减去入司年份计算

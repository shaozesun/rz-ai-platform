# 视频生成（对话窗口）

在**对话里**完成：上传 PPT（或直接给文字）→ 生成讲解视频 → 用自然语言改。侧边栏的「视频生成」页面（表单页）是另一条独立链路；用户在本对话里提需求时，直接按本技能做，不要把他支去那个页面。

> 命名：侧边栏有个独立的**「视频生成」表单页**（另一条链路，别把用户支过去）；本技能是**对话里**那条，产出物叫**讲解视频**。用户口语里两种说法都会出现（"生成个视频"/"做个讲解视频"），都按本技能处理。

## 何时用

- 用户要「把这份 PPT 做成讲解视频 / 配解说的视频 / 带配音的演示视频」
- 用户**没有 PPT、只贴了一段文字或大纲**，要「把这段内容做成讲解视频 / 讲成视频」
- 用户要「改视频里第几页的说法」「换成英文/换个音色重出」「画面别动」

只想看 PPT 内容（用 `list_uploaded_files` + `read_uploaded_file` 直接答），或要生成式画面/数字人（本平台不做）——这些不走本技能。

## 工作流

1. **确认输入**：PPT 需已作为本会话的附件上传。文件名不确定时先 `list_uploaded_files`；**逐字复制**它返回的原串传给 `video_create`——模型复述文件名时多一个空格或换了全半角括号，就会查不到文件（实测：真实名「副本伊顿UPS（93PR）…」，模型写成「副本伊顿 UPS（93PR）…」）。工具做了归一化兜底，但别依赖它。若附件卡片显示红字（如"文件 25.3MB 超过 20MB 上限"），说明那次上传**没有成功**，先请用户按提示重传（压缩图片或拆分），不要继续。
2. **生成前先报方案请确认**（用户要的是"先对一下，别直接跑"）：用**一条消息**列出拟定方案 + 请确认，**只列用户没交代的项**（他说了"用英文女声"，那两项就别再问）。确认项只限于平台真有的能力：

   > 拟定方案：面向 <受众> 的中文讲解视频；<画幅 16:9 横屏>；约 <3~5> 分钟；<普通话男声/女声/中性>；<配字幕 / 不要字幕>；<其它：如片尾加安全提示>。
   > 请确认或修改：主题/标题、画幅、配音（语言+音色）、字幕、时长、其它要求。

   - **不许承诺平台没有的能力**（用户提了就如实说做不到）：背景音乐/配乐、转场特效、重点局部放大、数字人、人物对白（本平台只有"页图 + 旁白 + 字幕"）。
   - 时长只能**近似**：它是按"目标分钟 × 实测语速（中文≈320 字/分钟、英文≈1040 字符/分钟）÷ 页数"折算成每页解说词字数上限（`target_minutes` 参数），成片实际时长由配音决定。交付时**如实报实际时长**（`video_status` 的 `duration_seconds`），别说成"精确 5 分钟"。
   - 用户回"可以/就这样"→ 开工；他改了哪项就只改那项。**别为确认堆一堆问题**——一次问清，一句话能答完。
- **改多页必须批量调**：逐页调 `video_update_page` 时，**同一个工具累计 20 次会被安全闸中止**（防死循环），50 页必然改到一半被掐断，而且每页都要重新拼一次整条视频。≥2 页一律用 `video_update_pages` 一次传完（一次调用改完、只拼一次）。
3. **创建**（按输入形态二选一；**这两个工具会等几分钟直到视频生成完才返回**，期间用户能看到实时进度）：
   - **有 PPT** → `video_create(ppt_filename, language, voice, aspect_ratio, motion?, subtitle_language?, show_subtitles?, target_minutes?, requirements?)`
   - **只有文字/大纲**（用户直接贴了内容，或没上传文件）→ `video_create_from_text(title, content, language, voice, aspect_ratio, motion?, subtitle_language?, show_subtitles?, target_minutes?, requirements?)`。
     `content` 传**完整原文**（可含 Markdown 标题分页，或用 `---` 显式分页），不要自己删改内容；平台会本地排版成页图（不依赖上传文件、也不需要 LibreOffice）。内容长不会丢——平台按画幅自动分页（页数变多而已）；但**这条路只有文字**：原文档里的图片、图表不会出现，用户想看原文版式与配图就请他上传 PPT 走 `video_create`。
   - **语言**：配音语言支持**中文/英文**（`language`，默认中文）。用户要是**别的语种**（日语/韩语等），如实说明目前只支持中英，别硬做。
   - **字幕**：默认烧、语言跟配音一致；用户说"不要字幕"传 `show_subtitles=False`，说"字幕跟配音不一样"才传 `subtitle_language`。
   - **其他确认结果落到参数**：目标时长 → `target_minutes`；受众/语气/片尾安全提示这类要求 → `requirements`（**原文**传进去，别改写）。
4. **交付**：工具返回时视频**已经生成好了**，所以**本轮回复里就要把视频给出去**——输出
   `<file url="{返回的 video_url}" name="{PPT名}.mp4"/>`（**原样复制**，别改写别加前缀），
   再配一两句说明。不要再说"稍后给你链接"、也不要让用户自己去找。
   - `finished=false`（等超时了，任务仍在后台跑）：如实说"还在生成，完成后卡片会自己出现"。
   - `ok=false`：如实转述错误本身，不要演绎成平台故障。
5. **查进度**：`video_status(task_id)`；卡住或失败时，把 `error` 与卡在哪一页如实说明。

## 一次完整回合长什么样

```
用户：把这份 PPT 做成讲解视频  （已附：副本伊顿UPS（93PR）标准操作流程(1)(2).pptx）
→ list_uploaded_files            # 拿到原文件名
→ video_create(ppt_filename="副本伊顿UPS（93PR）标准操作流程(1)(2).pptx")
  （工具会等 3~5 分钟，期间用户看到"正在生成视频：第 3/10 页"这类进度）
助手：视频已生成：<file url="{video_url}" name="副本伊顿UPS（93PR）标准操作流程(1)(2).mp4"/>
用户：第 3 页讲得太细了，用英文重出
→ video_pages(task_id="…", page_no=3)      # 先看现有文案
→ video_update_page(task_id="…", page_no=3, script="…完整英文文案…")   # 只重跑第 3 页，同样等它跑完
助手：已改好：<file url="{新的 video_url}" name="副本伊顿UPS（93PR）标准操作流程(1)(2).mp4"/>
```

## 二次修改（本技能的核心价值）

| 用户说 | 怎么做 |
|---|---|
| 「第 3 页讲得不对/改一下」（**单页**） | `video_pages(task_id, page_no=3)` 看现有文案 → `video_update_page(task_id, 3, "完整新文案")` 只重跑该页 |
| 「第 3、5、8 页都改成…」/「XX 页不要提 YY」（**多页**） | `video_pages(task_id)` 看文案 → **`video_update_pages(task_id, pages=[{"page_no":3,"script":"…"},{"page_no":5,"script":"…"}])` 一次传完** |
| 「换成英文」/「换个男声」 | `video_set_options(task_id, language='英文')` → `video_rerender(task_id)` |
| 「英文解说、中文字幕」/「字幕换成中文」 | `video_set_options(task_id, subtitle_language='中文')` → `video_rerender(task_id)`；只改某页字幕就配合 `video_update_page` 重去那一页 |
| 「第 5 页和第 7 页重做」 | `video_rerender(task_id, page_nos='5,7')` |
| 「第 4 页画面有问题（自检标了）」 | **注意：`video_rerender` 不会重渲页图**（它重写文案 + 重新配音 + 重编该页片段，页图复用现有那张）——画面类问题它修不了，如实说明；能修的是文案/配音类问题：`video_rerender(task_id, page_nos='4')` |

- `motion`：默认 `none`（静态画面，最清晰、编码也最快）；**不要主动加动效**，只有用户明确说"动起来/别太死板"时才传 `mixed`（按页轮换推近/平移）或 `zoom_in` 等
- **字幕是自动的**：解说词会默认烧成画面底部字幕（跟着该页配音同步），不需要用户开口、也没有开关参数；用户问起就如实说"已带字幕"。改文案后字幕会跟着该页一起重跑
- 文字路径与 PPT 路径的**二次修改完全一致**（同一套 `video_pages` / `video_update_page` / `video_set_options` + `video_rerender`）
- `video_update_page` 的 `script` 传**完整新文案**，不是"改动说明"
- 改动是增量的（只重跑受影响页 + 重新拼接），不必建议用户整份重做
- 重跑同样**等到跑完才返回**（返回的 `video_url` 就是新成品，本轮直接输出 `<file>`）；发起前先 `video_status` 确认上一次已跑完，避免并发重跑

## 常见错误

- **当前可用工具里根本没有 `video_create`**（不是它报错，是压根没这个工具）：说明**本环境未开启对话视频功能**（服务端开关 `VIDEO_AGENT_ENABLED=false`）。如实告诉用户"当前对话未启用视频生成，请联系管理员开启"，**不要**猜成"缺少 LibreOffice / 缺少中文字体"——那两条是**工具真的返回对应报错时**才成立的（分别由 `slides.ensure_ready()` / `text_pages.require_font()` 抛出原文），工具都不在时把它们当结论就是编，会把用户和运维都带偏方向。
- **没上传就建任务**：工具会返回"未找到文件 + 当前会话已上传列表"，据此请用户上传，别自己编文件名
- **返回"未安装 LibreOffice（soffice）"**：这是**环境缺依赖**，不是用户操作错。如实说明，并给出两条出路：
  ① 改用**文字/大纲**入口（`video_create_from_text`，不需要 LibreOffice）；② 让管理员在部署环境重建镜像后重试。不要反复重试同一个调用
- **返回"运行环境缺少 LibreOffice 可用的中文字体"**：同样是环境问题（缺字体时汉字会被渲染成空白，成片只剩英文和数字）。不要靠重试解决；请管理员确认部署镜像装了 `fonts-noto-cjk` 并 `fc-cache -fv` 后重试。**注意文字/大纲入口现在也会因缺字体明确报错**（`assets/fonts/wqy-microhei.ttc` 未提交进 git 就会缺），不再是"换个入口就能绕过"——如实说明是环境问题即可
- **页数超上限**（默认 60 页）：请用户拆分，或明确告知只处理前面的页
- **`degraded` 状态**：某页解说或配音失败，不是整体失败（该页按静音短页交付）；如实说明是"第 N 页没有配音"，可用 `video_rerender(page_nos='N')` 补救
- **`needs_review` 状态**：自检发现该页渲染可能异常（空白/乱码/被裁切），交付前主动请用户确认
- **看到"工具 X 累计调用 20 次，已超过上限，Agent 运行已中止"**：那不是视频坏了，是**防死循环的安全闸**（同一工具累计 20 次 / 连续 5 次完全相同调用）。已经执行过的页**是生效的**，剩下没改到的用 `video_update_pages` 批量补齐（一次传完，别再逐页调）
- **生成中重复建任务**：同一份 PPT 会得到多个任务；先 `video_status` 看有没有在跑
- **用户要求背景音乐/转场/局部放大/数字人**：本平台只有"页图 + 旁白 + 字幕"，这些做不到——如实说明，别答应下来再交付一个对不上的东西
- **用户要求"只改字幕、旁白不动"**：做不到——字幕是从配音稿派生的（同语言就是同一份，双语则按 `subtitle_language` 自动翻译）。要动字幕就得改文案（字幕跟着变）；如实说明，别悄悄改文案还说是"只改了字幕"
- **用户要求把某一页的**画面**重做（自检标了空白/乱码/被裁切）**：也做不到——`video_rerender` 不重渲页图（只重写文案+重新配音+重编片段）。如实说明：这类问题只能整条重新生成

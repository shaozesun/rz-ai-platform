# 事件单告警关联

把**事件工单的一次发生**对应到 DCIM 告警：给出告警时间、等级、设备、测点、告警内容、
**告警值**、四档阈值与越限档，并说明匹配依据（点位签名 / 时间窗唯一候选 / 模型仲裁）。

判定结论持久化在判定表（Mongo `event_alarm_link_decisions`，一行 = 一次发生，
键 = 工单号 + 发生时间 + 口径）。**报告判过的，对话直接复用；对话补判的，报告下一轮也复用。**

## 工作流

1. 调 `event_alarm_link(ticket_no, start, end, park, refresh, link_missing)`。
   - 用户给了工单号 → 传 `ticket_no`（如 `SJ20261030001`）。
   - 用户问某天/某区间 → 传 `start`/`end`（`YYYY-MM-DD`，含首尾；只给 `start` = 当天）。
   - 用户说园区 → 传 `park`（如 `廊坊`）；没说 → 留空 = 全国口径。**不要自己把 A1/A18
     这类楼宇名当园区**。
2. 按返回的 `mode` 交付（**不要自己另存文件、不要改写 url、不要重排或增删列**）：
   - `inline`（≤20 条）：**原样输出返回的 `table_markdown`**（服务端已按固定 16 列渲染好，
     空值写成「—」），再**原样输出 `file_tag`**（同内容的交互表格，可搜索/排序/翻页）。
     表格前后各加一两句结论即可。
   - `records`（>20 条）：原样输出 `file_tag`，再补一两句结论（条数、时段、关联情况）。
   - `empty`（0 行）：原样转述 `note`，不产文件。
3. 回答开头写清本次口径（用返回的 `scope`，有 `window` 时一并写），例如
   「以下为廊坊园区、2026-10-30 全天的事件单告警关联」。

**不要**用 `analysis_load` / `analysis_exec` 重算这份数据，也不要自己从告警查询工具里
重新拼一张表 —— 匹配口径（时间窗、机房码、点位签名、仲裁规则）只有工具里那一份。

## 参数

| 参数 | 含义 |
|------|------|
| `ticket_no` | 事件工单编号。与 `start` 至少给一个；同时给时以它为准 |
| `start` / `end` | 按**事件发生时间**的区间，`YYYY-MM-DD`（自然日含首尾）或 `YYYY-MM-DD HH:MM`；精度要一致，只给 `start` = 当天（带时分则 1 小时） |
| `park` | 园区口径（园区名或短名，如 `廊坊`）。留空 / `全国` = 全国口径。判定结论**按口径分开存**，园区报告与全国报告互不串用 |
| `refresh` | 默认 false：命中判定表直接出结论，不查库不调模型。仅用户明确要求「重新判定 / 刷新结论」时传 true（会重算并覆盖写回） |
| `link_missing` | 默认 true：判定表里没有的发生会补判（调综合管理平台取事件详情 + 查 DCIM 告警）。只想看已有结论、不想触发补算时传 false |

**日期区间会逐条补判区间内全部事件单**：大区间较慢（综合管理平台串行取详情），
如实告诉用户在补判，不要因为慢就改小范围或自行截断条数。

## 判定结论怎么解释

| `关联结论` | 含义 | 怎么回答 |
|------------|------|----------|
| 已关联 | 已确定告警身份 | 直接给告警时间/等级/设备/测点/告警值/阈值/越限档 |
| 未覆盖（非廊坊或早于 2026-10-29） | 不在 DCIM 告警覆盖范围 | 说明数据边界，**不得推断「没有告警」** |
| ±2 分钟内无告警 | 发生时间 ±120 秒内没有候选告警 | 如实说时间窗内没有候选；24 小时内的结论下次查询会重查（等数据落库） |
| 多候选待判定 | 多条候选、模型判不出 | 说明并列候选无法区分；**不猜** |
| 暂无法判定 | 档案不可用 / 仲裁调用异常 / 缺发生时间 | 说明原因，可稍后重试 |

`匹配方式` = `点位签名`（同一测点的确定性匹配）/ `时间窗唯一候选` / `模型仲裁`。
「说明」列是判定依据的文字说明，回答时可以引用，但**不要改写结论**。

## 口径与边界（回答用户时照此解释）

- **匹配只能启发式**：事件单里没有设备/点位/guid 字段，所以「已关联」是靠发生时间 ±120 秒、
  机房码收敛、点位签名与模型仲裁得出的；**不配优于配错**，宁可不配也不随便挂一条告警。
- **DCIM 告警当前只覆盖廊坊园区**（`廊坊A` / `廊坊B1M1` / `廊坊B1M2`），且**自 2026-10-29 起**
  才有数据。更早的期次、其他园区一律「未覆盖」——**未关联不等于没有告警**，不要说成
  「该事件没有告警」。
- **告警值取触发时刻**（不是当前值/恢复值），阈值印的是**告警触发条件**
  （`低于 x 或 高于 y` / `高于 y` / `低于 x`），不是正常取值范围；未配置印「—」。
- 全国口径的「部门」来自工单记录；判定表里早期写入的记录可能没有部门，显示「—」属正常。
- `refresh=true` 只在用户要求重新判定时用；常规查询一律默认复用，响应更快、结论也更稳定。

# pin_map — 点描地图（中国）

## 功能概述
在中国地图底图上按经纬度打点，点的大小随数值变化，适用于园区分布、站点/资产布点、按地点看工单或告警量等。
底图与点位都在前端本地渲染（不出内网）。

## 输入字段
### 必填
- `data`: array<object>，每条含四个字段（字段名按下面约定给，**不要改**）：
  - `园区`（string）：点位名称，如「廊坊园区」；
  - `经度`（number）：GCJ-02 坐标系；
  - `纬度`（number）：GCJ-02 坐标系；
  - `数量`（number）：该点的数值，决定点的大小。

### 可选
- `title`: string，图表标题。
- `height` / `width`: number，像素。

## 园区坐标对照表（GCJ-02）

**画点描图前先按园区名到这张表取坐标**，不要自己估。园区名取自 `mgmt.query_company_list`
返回的 **gardenName**。

| 园区 | 经度 | 纬度 |
|------|------|------|
| 廊坊园区 | 116.75 | 39.57 |
| 平湖园区 | 121.02 | 30.70 |

- 坐标系是 **GCJ-02**（与底图一致）。取坐标时请用高德/腾讯地图，**别用百度地图**（BD-09 会再偏一次）。
- **表里没有的园区不要打点**（宁可不画这个点，也不要编造坐标）；新增园区时在这张表里补一行。
- 坐标为上表所列的城市级位置，若需要厂区/楼栋级定位，请让维护者补充精确值。

## 使用示例

```html
<chart type="pin_map" title="各园区事件工单分布">
[{"园区":"廊坊园区","经度":116.75,"纬度":39.57,"数量":128},
 {"园区":"平湖园区","经度":121.02,"纬度":30.70,"数量":86}]
</chart>
```

## 使用建议
- 数量按园区聚合（如按工单量、告警量），先 `groupby(园区名)` 再用上面的表把坐标 join 进去。
- 点位名称与数值不在图上标文字，**鼠标悬停看 tooltip**（项目约定：图表上不加文字/数字标签）。
- 点位太少（<3 个）时优先直接用文字说明。

## 返回结果
- 按 `<chart>` 标签输出，数据由前端本地渲染（不出内网）；type 取本文件标题对应值。

# 文档更新检查（公司 × A 部门 × 25 项月度矩阵）

来源：「平台每月所需更新文件目录（修订版）」36 条清单里**只在范围内判定 25 条月度项**。
**每家公司的每个 A 部门**各有一份共享文档目录，检查口径是 **25 条清单项 × 各公司各部门**
（廊坊 A1、A2、A3、A5~A12、A18；平湖/惠州/佛山/重庆各 2~3 个，合计 21 个部门）。
**同名部门（A1、A2…）在不同公司是不同目录**，必须用 `company_name` 区分，别看错公司。
部门清单是**固定配置**（`DOC_UPDATE_DEPTS`），不随每次检查动态发现；`dept_columns` 里也可能
有 `dept_id` 为空、尚未解析出根目录的部门，如实说明即可。

判据按目录形态自动分两种：

- **按期提交型**（路径里有 `2026/9月`、`2026-09` 这类月份目录）：只看**本期应到月份**里
  有没有文件，不下载、不哈希，首轮就能出结论（能源月报、月度记录表、排班/考勤等）。
- **原地更新型**（没有月份目录，整定表/阈值表这类一份文件长期修改）：取内容哈希（sha256），
  与**上一期（上月）**快照比。

文档的 `updateTime` / `uploadTime` 字段不可信，**不要**用它判断。

## 工作流

1. 用户只是**问结果**（「这个月文档更新了吗」）→ 调 `doc_update_check`（默认 `sync=false`），
   直接读最近一期快照的比对结果，秒回。返回里 `depts` 是各部门汇总，`items` 每项带
   `company_name` / `dept_name`。
2. 用户问的是**某一个文档**（「能源月报更新了吗」「A1 的整定表查一下」）
   → 传 `name=` **文件名**（不是编号；清单名只是模糊叫法，**实际目录名也行**，
   如「能源管理报告」），**不要为了一个文件跑整期**。只取匹配到的项
   （各部门的该项），约 1~3 秒。
   - 返回 `candidates`（如只说「隐患排查表」「中控室」命中多项）→ 把候选**编号 + 名称**
     念给用户选，**不要**自己挑一个；
   - 返回 `error` + `available`（没匹配到）→ 请用户换个说法，或说明它不在 25 条月度项内；
   - 返回 `stored=false` → 本期还没有整期快照，本次结果没落库，要说明并建议先跑一次整期。
   - 用户点名了某个部门但工具返回多部门 → 按 `company_name` + `dept_name` 只讲那个部门
     （同名部门跨公司时按公司区分），其余可一句带过。
3. 用户明确要**现在重查全部**（「全部重新检查一遍」）→ 不传 `name`、传 `sync=true`。
   它会逐公司逐部门遍历共享树，约 **5~15 分钟**，期间平台会推送进度。
4. 回答口径：
   - 先说公司与部门、周期（如「廊坊 A1~A18，平湖/惠州/佛山/重庆各 2~3 个，共 21 个部门 × 25 项，
     `period_label`」），再给汇总。
   - **按期提交型**（`layout=period`）直接给「已更新 / 未更新（最新为 2026-09）/ 未找到」，
     不要提「基线」。
   - **原地更新型**（`layout=flat`）有上期才谈「已更新 / 未更新」；没有上期（`baseline=true`）
     只说「已建立基线，下期起比对是否更新」，**不要说「未更新」**，也不要拿本月早先的检查结果当参照。
   - **「未找到」「下载失败」不是「未更新」**，必须分开说，并提示需人工复核。
   - `warnings`（待复核）单列：档案类型与实际内容不符、或实际字节与档案大小差 >10%。
5. 用户想看具体哪几项没更新 → 用 `items` 里 `status=未更新` 的部门 + 编号 + 名称作答
   （Markdown 表格即可），不要复述全部格子。

## 边界

- **只覆盖月度项**（25 条）；实时 / 年度 / 年底 / 周 / 季度 / 半年度不在本功能范围，
  用户问到时说明这一点。
- **不要自己推算日期**：本期/上期、应到期月份都由平台在服务端确定。
- **不要用** `analysis_load`、文件接口或文档列表的 `version` 字段复算（`version` 实测是文档标题）。
- **`name` 传文件名**（清单项名、真实上传文件名、实际目录名都行，编号只是兜底），用户不会记 `1.6.6.1`。
- **匹配以实际名称优先**：清单里的名字是大概叫法，真实树里同一份文档可能叫
  「能源管理报告」「容量管理报告」「能源管理月报」等；返回的 `actual_dirs` 就是实际命中的目录，
  被问到「到底是哪份」时照它作答。
- 共享文件下载权限未开通时，原地更新型会显示「下载失败」并带权限提示；
  按期提交型不受影响。此时不要把它解释成「文件没更新」。
- 已知盲区：两次快照之间改了又改回去检测不到；对象存储里若是转换产物，跟踪的是产物哈希。
